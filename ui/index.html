NewAPI OpenAI 视频插件

兼容 OpenAI Sora / Grok / Seedream 等视频生成接口，支持自定义 API 地址、密钥、参考图上传、合规素材和 GitHub 自动更新。

图床配置

上游只接受公网图片 URL 时，本地参考图会先上传到图床，再把公网 URL 发送给 NewAPI。

图床上传接口地址，插件会把本地图片 POST 到这里，再读取返回的 URL。
如果图床接口需要 Bearer Token 认证，请填写。

生成参数

部分模型会限制时长，插件会按上游规则自动调整。
适用于 sd2-c6、sd2-c7、sd2-c8、sd2.5 及兼容的 CHRE Seedance 模型。
多图模式会发送参考图片 MAP、首帧和尾帧；首帧图模式适合只需要单张参考图的场景。
