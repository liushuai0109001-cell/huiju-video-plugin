NewAPI OpenAI 视频插件

兼容 OpenAI Sora / Grok / Seedream 等视频生成接口，支持自定义 API 地址、密钥、参考图上传、人物眼睛遮挡、去水印和 GitHub 自动更新。

图床配置

上游只接受公网图片 URL 时，本地参考图会先上传到图床，再把公网 URL 发送给 NewAPI。

图床上传接口地址，插件会把本地图片 POST 到这里，再读取返回的 URL。
如果图床接口需要 Bearer Token 认证，请填写。

生成参数

部分模型会限制时长，插件会按上游规则自动调整。
适用于 sd2-c6、sd2-c7、sd2-c8 及兼容的 CHRE Seedance 模型。
多图模式会发送参考图片 MAP、首帧和尾帧；首帧图模式适合只需要单张参考图的场景。

角色图眼睛自动处理

会生成处理后的临时参考图，不覆盖原角色图；支持正面、侧面、三视图。
可以选择你提供的自动人脸处理工具脚本；留空会使用插件内置版本。
用于运行 face_tool.py。

GitHub 自动更新

填写 GitHub 仓库，例如 liushuai0109001-cell/huiju-video-plugin。

下载后去水印

使用本地 FFmpeg delogo 工具重新编码视频，适合位置固定的角标或底部水印。
留空会自动使用插件内置或相邻目录中的 remove_watermark.py。
格式：x,y,w,h。多个水印写成 x,y,w,h;x,y,w,h。
越小越清晰、文件越大；建议 18-23。
